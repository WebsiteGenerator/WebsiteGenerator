03Deine Antworten bleiben in deinem Browser

Name, Pronomen, Beschreibung, Domain, Karten und Social-Media-Links, die du ins Terminal tippst, verarbeitet ein Skript direkt in deinem Browser. Es schickt sie an keinen Server, auch nicht an mich, und speichert sie nicht: Lädst du die Seite neu oder schließt du sie, sind sie weg.

Die Vorschau rechts entsteht ebenfalls lokal. „Download index.html“ erzeugt die Datei in deinem Browser und speichert sie auf deinem Gerät; dabei wird nichts hochgeladen.

Damit das Skript funktioniert, lädt es beim Start einmal die Stildatei template.css von diesem Server. Diese Anfrage enthält keine deiner Eingaben.

04Bilder in der Vorschau

Die Vorschau zeigt deine Website so, wie sie später aussieht. Dafür lädt dein Browser die Bilder, die du angibst, direkt von dort, wo sie liegen:

  • Bild-Adresse (URL): Dein Browser ruft das Bild beim jeweiligen Server ab. Dessen Betreiber erhält dabei deine IP-Adresse, deinen User-Agent und als Herkunft die Domain dieser Seite. Wer das ist, bestimmst du mit der Adresse, die du eingibst.
  • Bild-Code (z. B. github) sowie bei Karten- und Social-Media-Bildern jede Eingabe ohne Schrägstrich: Daraus wird eine Adresse bei raw.githubusercontent.com, das Bild kommt also von GitHub (siehe 05).
  • Relativer Pfad beim Hauptbild (z. B. bild.png): Den sucht dein Browser auf diesem Server. Der Pfad landet dann als aufgerufene Adresse im Server-Log von Vercel (siehe 02), das Bild wird natürlich nicht gefunden.

Das Vorschaubild für Link-Vorschauen (Thumbnail) lädt die Vorschau nicht. Klickst du in der Vorschau auf eine Karte oder ein Social-Media-Symbol, öffnet sich die eingetragene Adresse in einem neuen Tab; dort gilt die Datenschutzerklärung der Zielseite.

Diese Abrufe passieren nur, weil und wenn du die jeweilige Angabe machst. Rechtsgrundlage ist Art. 6 Abs. 1 lit. b DSGVO (die Vorschau ist die Funktion, die du nutzt), für GitHub zusätzlich lit. f.
